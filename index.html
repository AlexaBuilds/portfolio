Dominio Backend & Arquitectura ERP/CRM

Especialización en la arquitectura de Odoo ERP/CRM como sistema de gestión empresarial integral. El desarrollo backend se construye sobre Python 3.11 como lenguaje principal de servidor, interactuando con la base de datos PostgreSQL mediante el motor ORM (Object-Relational Mapping), y diseñando interfaces y flujos de trabajo avanzados con XML, QWeb y OWL (Odoo Web Library).

Lógica de Negocio Compleja & Ecosistema Enterprise

  • Gestión Empresarial Global: Modelado e integración de flujos complejos de inventario, sincronización de catálogos masivos, facturación, ventas multi-canal y estados de pedidos.

  • Políticas de mínimo privilegio con AWS IAM y reglas de cortafuegos en Security Groups.

Private Enterprise Client / NDA: Proyecto privado en producción para cliente exclusivo. Se detalla la arquitectura de pagos y seguridad sin revelar credenciales ni URLs públicas.

Retos de Ingeniería & Arquitectura Implementados

  • Pasarela Redsys API: Procesamiento seguro de pagos y suscripciones con firma de peticiones HMAC SHA-256 y notificaciones HTTP asíncronas de servidor.
  • Paywall & RBAC: Control de acceso por roles para diferenciar visitas públicas, blog de asesoramiento y suscriptores de contenido exclusivo.
  • Protección de Medios & Streaming (AWS S3 + CloudFront): Distribución privada de vídeo e imágenes mediante URLs firmadas de CloudFront (Signed URLs / Cookies), impidiendo descargas o enlaces directos no autorizados.
  • Hardening Frontend: Bloqueo de atajos de capturas de pantalla, prevención de insfilaración y marcas de agua dinámicas para la protección de autor.
